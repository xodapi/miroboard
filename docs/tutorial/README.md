# Учебные руководства MiroBoard

## Быстрый старт

MiroBoard — это офлайн-инструмент для работы с интерактивными досками и BPMN-схемами прямо в браузере. Откройте файл `dist/index.html` в Chrome или Edge — никакой установки и сервера не нужно. Создавайте фигуры и текст на холсте, сохраняйте работу в файл `.mboard` (который содержит всю историю изменений), а при необходимости — откатывайтесь к любому прошлому состоянию через встроенную временну́ю шкалу.

Если вы моделируете бизнес-процессы, воспользуйтесь встроенным BPMN-симулятором: расставьте задачи, шлюзы и потоки, задайте параметры длительности и ресурсов, а затем запустите детерминированный прогон или метод Монте-Карло, чтобы получить статистику по времени и стоимости.

# MiroBoard Tutorials

## Quick Start

MiroBoard is an offline whiteboard and BPMN-diagramming tool that runs entirely in your browser. Open `dist/index.html` in Chrome or Edge — no installation or server required. Draw shapes and text on the canvas, save your work to a `.mboard` file (which bundles the full change history), and roll back to any past state through the built-in timeline.

If you are modelling business processes, use the built-in BPMN simulator: place tasks, gateways, and flows, configure duration and resource parameters, then run a deterministic token pass or a Monte Carlo simulation to get time and cost statistics.
